### 5. 時間枠の表示を「15:00」形式に統一

#### 問題
- EventInfoSectionで時間枠が「15」「16」「17」と表示されていた
- 「15:00」「16:00」「17:00」形式で表示したい

#### 対応
- `EventInfoSection.tsx` で時間枠の表示ロジックを修正
- 時間文字列を処理して「15:00」形式に変換
  - 「15:00-15:45」形式の場合: 開始時刻「15:00」を抽出
  - 「15」のみの場合: 「15:00」に変換

#### 実装
```typescript
const slots = data.slots.map((slot: { id: string; available: boolean }) => {
  const timeString = slotTimeMap[slot.id] || slot.id;
  let displayTime = timeString;
  if (timeString.includes("-")) {
    displayTime = timeString.split("-")[0];
  } else if (/^\d+$/.test(timeString)) {
    displayTime = `${timeString}:00`;
  }
  return {
    id: slot.id,
    time: displayTime,
    available: slot.available,
  };
});
```

#### 結果
- 時間枠が「15:00」「16:00」「17:00」形式で表示されるようになった

- `src/components/EventInfoSection.tsx`
