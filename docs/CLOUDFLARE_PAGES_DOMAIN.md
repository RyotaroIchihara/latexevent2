# Cloudflare Pages ドメイン変更ガイド

## 現在の状況

- 現在のURL: `ameya1206.pages.dev`
- プロジェクト名を `latexbearty` に変更したが、URLが変わらない

## 重要なポイント

**Cloudflare Pagesでは、プロジェクト名を変更しても既存の `.pages.dev` ドメインは自動的に変更されません。**

`.pages.dev` ドメインは、プロジェクト作成時に一度だけ設定され、その後は変更できません。

## 解決方法

### 方法1: カスタムドメインを設定（推奨）

既存のプロジェクトにカスタムドメインを追加する方法：

1. **Cloudflare Dashboard → Pages → プロジェクトを選択**
2. **「Custom domains」タブを開く**
3. **「Set up a custom domain」をクリック**
4. **カスタムドメインを入力**（例: `latexbeauty.com` または `latexbeauty.yourdomain.com`）
5. **DNS設定を確認して保存**

**注意**: カスタムドメインを設定するには、そのドメインをCloudflareで管理している必要があります。

### 方法2: 新しいプロジェクトを作成

新しい `.pages.dev` ドメインを使用する場合：

1. **新しいプロジェクトを作成**
   - Cloudflare Dashboard → Pages → 「Create a project」
   - プロジェクト名: `latexbeauty`（希望する名前）
   - GitHubリポジトリを接続
   - ブランチ: `main`
   - ビルド設定: `npm run build`
   - 出力ディレクトリ: `build`

2. **環境変数を設定**
   - 新しいプロジェクトの Settings → Environment variables
   - 既存のプロジェクトと同じ環境変数を設定

3. **古いプロジェクトを削除（オプション）**
   - 古いプロジェクト（`ameya1206`）を削除するか、そのまま残すか選択

**メリット**: 新しい `.pages.dev` ドメイン（`latexbeauty.pages.dev`）が使用可能

**デメリット**: 新しいプロジェクトを作成する必要がある

### 方法3: プロジェクトを削除して再作成

既存のプロジェクトを削除して、同じリポジトリから新しいプロジェクトを作成：

1. **既存のプロジェクトを削除**
   - Cloudflare Dashboard → Pages → プロジェクト選択
   - Settings → 「Delete project」

2. **新しいプロジェクトを作成**
   - プロジェクト名: `latexbeauty`
   - 同じGitHubリポジトリを接続
   - 環境変数を再設定

**注意**: この方法では、既存のデプロイ履歴が失われます。

## 推奨される方法

### カスタムドメインがある場合

**方法1（カスタムドメイン設定）**を推奨します。既存のプロジェクトをそのまま使用でき、カスタムドメインでアクセスできます。

### カスタムドメインがない場合

**方法2（新しいプロジェクト作成）**を推奨します。既存のプロジェクトを残しつつ、新しい `.pages.dev` ドメインを使用できます。

## 現在のプロジェクト名の確認

Cloudflare Dashboardで以下を確認：

1. **Pages → プロジェクトを選択**
2. **Settings → General**
3. **「Project name」を確認**

プロジェクト名は変更できますが、`.pages.dev` ドメインは変更されません。

## 注意事項

- `.pages.dev` ドメインは一度設定されると変更できません
- プロジェクト名とドメイン名は別物です
- カスタムドメインを設定するには、そのドメインをCloudflareで管理している必要があります
